## Query Processing Pipeline

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           QUERY PROCESSING                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   SQL: SELECT * FROM orders WHERE user_id = 5 ORDER BY created_at;          │
│                                                                              │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  1. PARSER                                                            │  │
│   │     • Lexical analysis (tokenize)                                     │  │
│   │     • Syntax analysis (grammar check)                                 │  │
│   │     • Output: Parse Tree                                              │  │
│   └────────────────────────────────┬─────────────────────────────────────┘  │
│                                    ▼                                         │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  2. ANALYZER                                                          │  │
│   │     • Semantic analysis                                               │  │
│   │     • Resolve table/column names                                      │  │
│   │     • Check permissions                                               │  │
│   │     • Type checking                                                   │  │
│   │     • Output: Query Tree                                              │  │
│   └────────────────────────────────┬─────────────────────────────────────┘  │
│                                    ▼                                         │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  3. REWRITER                                                          │  │
│   │     • Apply rewrite rules                                             │  │
│   │     • Expand views                                                    │  │
│   │     • Handle RLS policies                                             │  │
│   │     • Output: Rewritten Query Tree                                    │  │
│   └────────────────────────────────┬─────────────────────────────────────┘  │
│                                    ▼                                         │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  4. PLANNER / OPTIMIZER                                               │  │
│   │     • Generate possible plans (join orders, access methods)           │  │
│   │     • Estimate costs using statistics                                 │  │
│   │     • Choose cheapest plan                                            │  │
│   │     • Output: Execution Plan                                          │  │
│   └────────────────────────────────┬─────────────────────────────────────┘  │
│                                    ▼                                         │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  5. EXECUTOR                                                          │  │
│   │     • Execute plan nodes (scan, join, sort)                           │  │
│   │     • Access data via buffer manager                                  │  │
│   │     • Handle transactions                                             │  │
│   │     • Return results to client                                        │  │
│   └──────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Storage Hierarchy

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          STORAGE HIERARCHY                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   DATABASE CLUSTER ($PGDATA)                                                │
│   └── base/                                                                 │
│       └── 16384/              (database OID)                               │
│           ├── 16385           (table file: users)                          │
│           ├── 16385.1         (extension if > 1GB)                         │
│           ├── 16386           (table file: orders)                         │
│           ├── 16387           (index file)                                 │
│           └── ...                                                          │
│                                                                              │
│   TABLE FILE                                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │  Page 0  │  Page 1  │  Page 2  │  Page 3  │  ...  │  Page N        │  │
│   │  (8KB)   │  (8KB)   │  (8KB)   │  (8KB)   │       │  (8KB)         │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
│   PAGE (8KB)                                                                │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │  Page Header (24 bytes)                                              │  │
│   │  • pd_lsn, pd_checksum, pd_flags                                    │  │
│   │  • pd_lower (free space start), pd_upper (free space end)           │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │  Item Pointers / Line Pointers (4 bytes each)                       │  │
│   │  [1] → offset 8000  [2] → offset 7800  [3] → offset 7600           │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │  FREE SPACE                                                          │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │  Tuple 3 (offset 7600)                                               │  │
│   │  Tuple 2 (offset 7800)                                               │  │
│   │  Tuple 1 (offset 8000)  ← Tuples grow from bottom up                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
│   TUPLE                                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │  Header (23+ bytes)                                                  │  │
│   │  • t_xmin (creating txn), t_xmax (deleting txn)                     │  │
│   │  • t_ctid (current location), t_infomask (flags)                    │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │  NULL Bitmap (optional)                                              │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │  User Data (column values)                                           │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## MVCC - Multi-Version Concurrency Control

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                MVCC                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   UPDATE users SET name = 'Bob' WHERE id = 1;  (Transaction 200)            │
│                                                                              │
│   BEFORE UPDATE:                                                            │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  Tuple: {id: 1, name: 'Alice'}                                       │  │
│   │  t_xmin = 100 (created by txn 100)                                   │  │
│   │  t_xmax = 0   (not deleted)                                          │  │
│   │  t_ctid = (0, 1)                                                     │  │
│   └──────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
│   AFTER UPDATE:                                                             │
│   ┌──────────────────────────────────────────────────────────────────────┐  │
│   │  Old Tuple: {id: 1, name: 'Alice'}  ← DEAD                           │  │
│   │  t_xmin = 100                                                        │  │
│   │  t_xmax = 200  ← Now marked deleted by txn 200                       │  │
│   │  t_ctid = (0, 5)  ← Points to new version                            │  │
│   │                                                                       │  │
│   │  New Tuple: {id: 1, name: 'Bob'}    ← LIVE                           │  │
│   │  t_xmin = 200  ← Created by txn 200                                  │  │
│   │  t_xmax = 0                                                          │  │
│   │  t_ctid = (0, 5)                                                     │  │
│   └──────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
│   VISIBILITY RULES:                                                         │
│   Transaction 150 (started before 200): Sees 'Alice'                        │
│   Transaction 250 (started after 200 commits): Sees 'Bob'                   │
│   Transaction 200 (self): Sees 'Bob'                                        │
│                                                                              │
│   VACUUM eventually removes dead tuples when no transaction needs them      │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
