# PostgreSQL Odyssey — Web App

Interactive 15-episode visual journey through PostgreSQL internals, built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and GSAP.

Live at **[postgres-odyssey.vercel.app](https://postgres-odyssey.vercel.app)** · See the [root README](../README.md) for the full curriculum and Docker lab.

## Commands

```bash
npm install
npm run dev       # Start local dev server
npm run build     # Type-check and build production bundle
npm run preview   # Preview production build
```
